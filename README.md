
# Prakhar Varshney | Developer Portfolio

A responsive, 3D-inspired personal portfolio website built using **HTML, CSS, and JavaScript**. It features a futuristic dark theme, purple accents, interactive animations, and a clean layout to showcase my skills, projects, and education.

## ✨ Features

- 🎨 Modern dark theme with purple accents
- 🧊 3D-inspired hero section with animated visual elements
- 📱 Fully responsive design for desktop, tablet, and mobile
- 🖱️ Custom cursor and interactive hover effects
- ✨ Scroll-based reveal animations
- 🧭 Responsive navigation with a mobile menu
- 💻 Dedicated sections for skills, projects, and education
- 📬 Contact section with social links

## 🛠️ Tech Stack

- **HTML5** — Website structure
- **CSS3** — Styling, responsive layouts, animations, and 3D effects
- **JavaScript** — Interactivity, navigation, and scroll effects

## ⚙️ Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/prakhar-117/3dResponsivePortfolio.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for local development.
